# CoreLib



CoreLib is a project that aims to have everything that I need, all in one project.



## Features:



|No-Overhead Component System (Init, Update, Unload templates, and togglable on and off)|
|-|
|One-Library only deal (combines SDL3, SDL3\_ttf, SDL3\_mixer (not yet), and more libraries if possible into one for easy usage.)|
|Replaces the standard library (Not entirely, use it if you want to!)|
|Cross-Platform (currently Desktop platforms only, going to support many consoles \& more soon)|
|Focuses on fast code \& a consistent code base.|
